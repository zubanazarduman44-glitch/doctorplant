# 🌿 Өсімдік дәрігері / Доктор растений

Өсімдікті суретке түсіріңіз — ЖИ түрін, жағдайын, ауруын анықтап, күтім бойынша кеңес береді.
Сфотографируйте растение — ИИ определит вид, состояние, болезнь и даст советы по уходу.

**MVP** · Next.js + Google Gemini · Vercel

## Қалай жұмыс істейді / Как работает

1. Пайдаланушы сурет жүктейді → браузер оны кішірейтіп, геолокацияны өшіреді
2. Сурет `/api/diagnose` серверіне жіберіледі
3. Сервер Gemini-ден JSON түрінде жауап сұрайды
4. Сайт нәтижені көрсетеді: түрі, сенімділік, диагноз, емдеу, күтім

## Файлдар

| Файл | Не істейді |
|---|---|
| `app/page.js` | Сайттың беті (интерфейс) |
| `app/api/diagnose/route.js` | Сервер: Gemini-ге сұраныс, промпт |
| `app/globals.css` | Дизайн |

## Баптау / Настройка

Vercel → Project → Settings → Environment Variables:

```
GEMINI_API_KEY = <сіздің кілтіңіз>
```

⚠️ Кілтті ешқашан кодқа немесе GitHub-қа жазбаңыз.
